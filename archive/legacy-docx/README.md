# Legacy Word inputs - non-authoritative

The files in this directory are historical source artifacts used during the
initial conversion to the controlled LaTeX corpus. They are retained for
provenance only.

They are not the current requirements authority, are not maintained in parallel
with the controlled LaTeX and Stage A specification files, and must not be used
to resolve a conflict or generate a release. Any proposed recovery of content
from these binaries requires document-control review and an explicit traceable
change to the authoritative source.
